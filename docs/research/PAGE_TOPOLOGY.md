# Vera News page topology

Reference: the user-supplied Substack feed screenshot and the public Substack home feed.

1. Persistent product navigation
   - Desktop: existing left rail.
   - Mobile: existing bottom navigation.
   - Interaction: route navigation.
2. News header
   - One plain `News` heading.
   - Search input immediately below or beside the heading.
   - Interaction: search filters visible cards as the user types.
3. Audience tabs
   - Exactly two tabs: `Journalists` and `Activists`.
   - Interaction: click/tap filters the feed without navigating.
4. Article feed
   - Single centered column.
   - Repeating author header, short post copy, optional media preview, linked article title, and engagement actions.
   - Interaction: vertical document scroll; buttons use clear focus/pressed states.

The page deliberately excludes a marketing hero, explanatory right rail, category grid, and repeated funding copy. Funding remains a separate top-level destination.
