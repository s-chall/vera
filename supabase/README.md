# Local Supabase notes

- `config.toml` is generated by `supabase init` and checked in so `supabase start` works out of the box.
- Migrations live in `migrations/`; do not edit applied filenames — add new timestamped files instead.
- `mocks/contract-adapter.mjs` is a stand-in for `PAYOUT_CONTRACT_ADAPTER_URL` during local finalize runs.
- `seeds/local_payout_epoch.sql` inserts a closed `open` epoch for curling `finalize-payout`.
- Put function secrets in `.env.local` (gitignored). See the root `.env.example`.
