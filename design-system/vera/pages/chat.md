# Chat

## Purpose

Let contributors paste the Bitcoin address they used to fund the Total Pool, then see which epoch they funded and how sats were distributed to journalist pseudonyms. Media reuse links from the NPR + BBC Mundo allowlist appear as citations. Inference prefers Maple / local Ollama; otherwise grounded templates. Journalist work is not sent to cloud training APIs.

## Content hierarchy

1. Chat title + one short line.
2. Deposit address field (Follow).
3. Suggested prompts.
4. Thread with payout briefs and outbound media links.
5. Composer.

## Visual rules

- Match Fund: paper background, single column, ink/orange accents.
- No marketing trust cards. No dashboard chrome.
- Assistant bubbles quiet; user bubbles slightly stronger.
- Keep Maple note as small meta text, not a hero claim.
